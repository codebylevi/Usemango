# ManGO — usemango.vercel.app

One-page ManGO Digital Marketplace website built with plain HTML, CSS and JavaScript.

## Included
- Long, scrollable one-page layout
- Responsive mobile design
- ManGO logo
- Favicon
- Dedicated WhatsApp chat section
- Dedicated QR-code section
- QR code linked to ManGO WhatsApp Business
- Prefilled WhatsApp message
- Services: Food, Groceries, Parcels, Gadgets and more
- Sticky navigation
- Mobile navigation
- No framework required

## Deploy to Vercel
1. Create a GitHub repository named `usemango`.
2. Upload every file and folder in this project.
3. Import the GitHub repository into Vercel.
4. For a plain static site, leave the build settings at their defaults / no framework.
5. Deploy.
6. If the project name `usemango` is available, the address will be `usemango.vercel.app`.

## Important
The QR library is loaded from jsDelivr. If you want a fully offline version later, the QR library can be stored locally in the project.
